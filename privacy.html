Privacy

This page explains what this website collects and which outside services it uses. It covers the website only; Chartered has its own privacy section.

What this site collects

This site has no accounts, no analytics and no advertising trackers, and it does not set cookies. Fonts and images are served from this site itself.

Outside services

  • GitHub Pages hosts this site. Like any web host, GitHub receives standard request information, such as your IP address, when you load a page. See the GitHub General Privacy Statement.
  • GitHub API: the Chartered page asks GitHub how many times the installer has been downloaded, so your browser contacts api.github.com when you open that page.
  • GitHub Releases: Chartered downloads are served by GitHub.
  • Web3Forms: when our contact form is switched on, messages are sent through Web3Forms, which emails them to the person you choose.

Contact messages

If you write to us, we receive your name, email address, the topic you pick and your message. We use them only to reply and follow up. We keep messages only as long as needed to reply and follow up, and we do not share your email address.

Questions

Ask either of us through the contact page.
