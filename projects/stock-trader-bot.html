Stock Trader Bot

Can a machine learning strategy beat buying and holding an index fund, after trading costs, on data it was never tuned on?

python · r · backtesting

The question

Can a model built on public data beat buying and holding the S&P 500 on risk-adjusted return, after trading costs, on data it was never trained or tuned on?

Where it stands

The first code is in place: a check that compares free sources of daily prices, so we can choose a reliable one before building on it.

How it will be tested

The backtesting harness comes first: walk-forward testing, trading costs and slippage, and no access to future data. The strategy is judged against buying and holding an index fund, and against simple momentum and mean-reversion rules. Machine learning models come only after that, and anything promising is paper traded before real money is involved.

A strategy has to hold up across many separate test periods, not one favorable stretch of the market. If nothing beats the index fund, we will document that clearly; it is a useful answer too.
