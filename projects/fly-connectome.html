Fly Connectome

What can the complete wiring diagram of a fruit fly's brain tell us about how a brain is organized?

Python · network science · neuroscience data

The question

Still being chosen. The options are analyzing the network's structure, using the real wiring as a neural network's architecture, or reproducing and extending a published whole-brain model.

Where it stands

The connectome data is downloaded. The next step is choosing which research question to pursue first.

How it will be tested

That depends on the question. A structure analysis would compare the real wiring against random networks with the same structure. An architecture test would check whether real wiring gives a neural network a head start over random wiring of the same density. A reproduction would rebuild a published whole-brain spiking model before running a new experiment with it.
