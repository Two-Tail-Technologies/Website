Fly Connectome

A research project on the fruit fly connectome, the complete wiring diagram of a fly's brain.

Status
Idea
Started
November 1, 2026
Team
Mark Scott
Tools
Python, Network science, Neuroscience data

The question

The research question is still being chosen. The options are network-structure analysis, using the real wiring as a neural network's architecture, or reproducing and extending a published whole-brain model.

Where it stands

  • The connectome data is downloaded. The question comes next.

How we're approaching it

  • Compare the real wiring against random networks with the same structure.
  • Test whether real wiring gives a neural network a useful head start over random wiring of the same density.
  • Or reproduce a published whole-brain spiking model, then run a new experiment with it.
