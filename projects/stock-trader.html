Idea

Stock Trader Bot

A machine learning trading strategy, judged honestly against simply buying and holding an index fund.

Status
Idea
Started
November 1, 2026
Tools
Python, R, Backtesting

The question

Can a model built on public data beat buy-and-hold of the S&P 500 on risk-adjusted return, after trading costs, on data it was never trained or tuned on?

Where it stands

  • The first code is in place: a test that compares free daily price sources before we pick one.

How we're approaching it

  • Build the backtesting harness first: walk-forward testing, trading costs and slippage, and no peeking at future data.
  • Set simple baselines: buy-and-hold, momentum and mean-reversion rules.
  • Only then try machine learning models against those baselines.
  • Paper trade before any real money.

A clearly documented null result is a valid outcome.

Why it matters

  • Most hobby trading results come from flawed backtests. A rigorous backtesting framework and an honest write-up are worth showing even if the strategy does not beat the market.
