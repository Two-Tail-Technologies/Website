Company Profitability

Can public SEC filings forecast a company's profitability several quarters ahead better than simple baselines?

panel forecasting · sec filings · [NEEDS: python or r]

The question

Using only information that was public at the time, can a model forecast a profitability measure several quarters ahead better than simple baselines?

Where it stands

The project is scoped. Still open: which profitability measure to forecast, how far ahead and for which companies. Its forecasts are planned as an input to the Stock Trader Bot.

How it will be tested

Every value in the dataset is dated by when it was filed, so the model never sees information before it was public. It has to beat two baselines: next quarter equals the last, with and without seasonality. Regularized regression comes first, then gradient boosting, scored with rolling walk-forward tests on data the model hasn't seen.
