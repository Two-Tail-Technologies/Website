Idea

Company Profitability

Forecasting a company's profitability several quarters ahead from public SEC filings.

Status
Idea
Started
November 1, 2026
Tools
R or Python, Panel forecasting, SEC filings

The question

Using only information that was public at the time, can a model predict a profitability measure several quarters ahead better than simple baselines?

Where it stands

  • Scoped. Target measure, forecast horizon and company universe are still open.

How we're approaching it

  • Build a point-in-time dataset where every value is dated by when it was filed.
  • Baselines: next value equals the last value, with and without seasonality.
  • Models: regularized regression, then gradient boosting.
  • Evaluate with rolling, walk-forward tests on data the model has not seen.
