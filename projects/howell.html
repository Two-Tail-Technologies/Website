In progress

Howell

Our own survival city-builder, inspired by Banished, built so that both people and a trained reinforcement learning agent can play it.

Status
In progress
Started
November 9, 2026
Team
Mark and Aaron Scott
Tools
Python, Godot 4, Reinforcement learning

The question

Can an agent that plays through exactly the same commands and information as a human keep a colony alive, and hit efficiency targets, on random seeds and scenarios it has never seen?

Where it stands

  • v0 is built and tested (November 11, 2026). It has a console version of the game, a rule-based bot, and a first trained agent. On 20 seeds it never trained on, the agent scored 1,235.4 with every colony surviving, against the rule-based bot's 1,067.4. v0 ships as a Windows program that was checked on a clean machine.
  • v1 is in active development. It replaces population counts with individual villagers: households and housing, births and deaths, retirement, schools and education, harsh winters and accidents, endless play, and a tuning tool for game balance.
  • Next: a Godot game window with real-time controls, then a Training screen and the v1 release.

How we're approaching it

  • Build a headless simulation first. The same seed and the same commands always produce the same game, so humans, the agent and replays all share one engine.
  • Grow it in stages. Each stage ships its own Windows program with a Player mode and a Training mode.
  • A rule-based bot must survive most seeds before any machine learning, and the agent has to beat that bot.
  • Always score on held-out seeds. Training rewards are never part of the reported score.
  • Play fair. The agent only sees figures a player can find in the game's interface.
Next: Economic Planning Bot

Why it matters

  • A complete original system: a game simulation, a training pipeline and a playable demo.
  • A game we actually want to play.
  • A possible product: a playable game with a mode where you watch the agent run the town.
