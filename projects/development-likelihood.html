Development Likelihood

Can public parcel, permit, land-cover and aerial-imagery data predict which land parcels will be developed within a few years?

geospatial · gradient boosting · survival models

The question

For each parcel in a study area, what is the probability it is developed within a set number of years, and does that probability hold up in an area the model never saw?

Where it stands

The project is scoped and will start with a single county. The exact study area, the time horizon and the definition of “developed” are still to be decided.

How it will be tested

The baseline is a simple distance-and-zoning model. Gradient boosting and a survival (hazard) model have to beat it on whole towns or map blocks held out from training, and the probabilities are checked for calibration.
