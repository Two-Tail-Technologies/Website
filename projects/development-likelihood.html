Idea

Development Likelihood

Predicting which land parcels will be developed within a few years, using public parcel, permit, land-cover and aerial-imagery data.

Status
Idea
Started
November 1, 2026
Tools
Geospatial, Gradient boosting, Survival models

The question

For each parcel in a study area, what is the probability it is developed within a set number of years, and does that probability hold up in an area the model never saw?

Where it stands

  • Scoped. The study area, the time horizon and the definition of "developed" are still to be decided.

How we're approaching it

  • Choose one county to start and one consistent definition of "developed".
  • Build a parcel-by-year dataset of features and later outcomes.
  • Baseline: a simple distance-and-zoning model.
  • Models: gradient boosting and a survival (hazard) model.
  • Test on whole towns or map blocks held out from training, and check that the probabilities are calibrated.

Why it matters

  • Developers, land investors, solar siting teams, utilities and planners all need this.
  • The hard part is cleaning and joining messy public data, which makes the work hard to copy.
